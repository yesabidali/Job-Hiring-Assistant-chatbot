# TalentScout Hiring Assistant

This is an AI-powered Hiring Assistant. This chatbot helps in the initial screening of candidates by gathering essential information and asking relevant technical questions based on their chosen tech stack. It is designed to make the hiring process easier by collecting candidate details, generating technical questions, and ensuring a smooth interview experience.

## Features

- Candidate Information Collection – Gathers details such as name, email, years of experience, and tech stack.  
- AI-Generated Technical Questions – Automatically creates custom technical questions based on the candidate's tech stack.  
- Seamless Conversation Handling – Ensures a natural and interactive interview experience.  
- Secure Data Storage – Saves candidate information safely for later review.  
- Easy Deployment – Built with Streamlit for quick and hassle-free setup.  

## Installation & Setup

Follow these steps to set up and run TalentScout Hiring Assistant on your system:

### Clone the Repository
```bash
git clone https://github.com/yourusername/talentscout-hiring-assistant.git
cd talentscout-hiring-assistant
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

### Run the Application
```bash
streamlit run app.py
```

## Requirements
Ensure you have the following installed:
- Python (>=3.7)
- Pip (latest version recommended)
- Streamlit (for UI)
